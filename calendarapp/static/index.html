      How to add it to a phone

      Android: install DAVx5, add an account with "Login with URL and user name", use the server, user name and app password above, then pick the calendars to sync.

      iPhone: Settings, Calendar, Accounts, Add Account, Other, Add CalDAV Account. Server: the host name from the server address above, without https:// or /dav/, then the user name and app password.
